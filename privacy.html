Privacy Policy

Effective 21 October 2026

This policy describes the intended data handling of Seki Job Calendar, operated for personal use by zhentianxingcun93-bot.

Data accessed and purpose

  • Calendar data: event details, event identifiers, relevant time ranges and free/busy information are accessed to manage application deadlines and confirmed interviews, check conflicts and prevent duplicates.
  • Authorization data: an OAuth client ID, client secret and refresh token allow unattended Calendar access after the owner gives consent. Short-lived access tokens are obtained as needed.
  • Related job-search data: company identifiers, source references, relevant message extracts and dates, candidate events, confirmation records and execution results may be stored by the companion job-search program. Its separate Gmail connection uses read-only mailbox access; the Calendar OAuth scopes do not grant Gmail access. Not every message is scanned.

Storage and retention

Operational data and logs are stored on the operator's Oracle Cloud virtual machine. Calendar OAuth credentials are stored in a local file with owner-only permissions; these permissions are not encryption. Managed calendar entries are stored by Google. The current utility does not implement a comprehensive automatic retention/deletion schedule; records remain until the operator deletes them or applies a retention policy. Any operator-created backups may also contain retained records.

Sharing and limited use

Google receives requests needed to perform authorized Calendar operations. Oracle Cloud hosts the running program and its stored data. The documented utility does not sell Google user data, use it for advertising, or transfer it to AI model providers for model training. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Control, revocation and deletion

The owner can revoke access through Google Account connections and can stop the Oracle calendar and mail timers. Revoking access does not delete existing calendar entries or local records. The owner must separately delete managed events from Google Calendar, remove local credentials and retained program data, and handle any backup copies. For assistance, contact zhentianxingcun93@gmail.com. Do not email credentials or tokens.

This public documentation website

This static site has no application login, forms, analytics scripts, advertising scripts or program credentials. GitHub Pages hosts it and may log visitor IP addresses and other service data for security; see the GitHub Privacy Statement. Visiting this site does not grant the program access to your Google account.

Changes

The operator should update this policy before materially changing the program's data access, use, sharing or retention. The effective date is shown above.
