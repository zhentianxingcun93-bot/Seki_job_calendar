1. https://github.com/new で所有者を上記ユーザー名に設定。
2. Repository name に seki-job-calendar、Public、Add README をONにして作成。
3. ZIPをiPadの「ファイル」アプリで展開。
4. リポジトリで Add file > Upload files を選び、index.html / privacy.html / terms.html の3ファイルだけをアップロードしCommit changes。
   フォルダやZIPそのものをアップロードしないでください。トップ階層にindex.htmlが必要です。
5. Settings > Pages > Build and deployment > Source: Deploy from a branch。
6. Branch: main、/(root)、Save。公開URLが表示され、アクセスできるまで待ちます。
