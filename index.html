Seki Job Calendar

就職活動に関する期限・面接予定を管理する、所有者本人専用のカレンダー連携プログラムです。この公開サイトは説明用で、ログインや認証情報の入力は受け付けません。

Seki Job Calendar is a personal utility operated by zhentianxingcun93-bot. The automation runs on the operator's Oracle Cloud virtual machine. This website contains documentation only; it does not connect to the visitor's calendar.

What the program does

  • Checks the authorized owner's calendar availability to identify scheduling conflicts.
  • Creates or updates application-related deadline reminders when a supported, sufficiently verified date is available.
  • Requires the owner's explicit confirmation before creating a proposed interview event.
  • Uses event identifiers and ownership markers to avoid duplicate entries and to restrict updates to events it manages.

The wider job-search program also collects public job listings and can send previously verified job applications under the owner's instructions. Calendar authorization does not itself authorize Gmail access or send job applications. A separately configured Gmail connection checks relevant messages.

Google Calendar access

The program requests calendar.events.owned to read and manage events on calendars the authorized account owns, and calendar.freebusy to check availability. These permissions are broader than the program's intended use; the application logic restricts its writes to managed application-related events. This is not a Google product and is not represented as verified or endorsed by Google.

Availability and limits

This is a single-owner utility, not a public sign-up service. Unknown dates, unsupported message formats, conflicting schedules or missing authentication may require manual attention. The program cannot guarantee that every email, deadline or interview is detected.
